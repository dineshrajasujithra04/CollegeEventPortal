## 📌 Project Overview

The **College Event Portal — TechFest 2026** is a front-end web application developed using HTML5, CSS3, and JavaScript.

The website provides a central platform for students to explore college festival events, view event schedules, learn about competitions, and interact with an event registration form.

The application includes a homepage, event listings, announcements, a schedule table, an image gallery, and contact information. JavaScript adds interactive functionality to the user interface.

This project demonstrates the development of a static website using fundamental front-end technologies.

## ✨ Key Features

* 🏠 **Homepage:** Introduces TechFest 2026 and its theme.
* 📢 **Announcements:** Displays festival announcements and updates.
* 🎯 **Event Listings:** Showcases technical and non-technical competitions.
* 📝 **Event Registration:** Provides a form for entering participant details and selecting an event.
* 📅 **Event Schedule:** Displays event dates, timings, names, and venues.
* 🖼️ **Event Gallery:** Showcases images representing festival activities.
* 📞 **Contact Section:** Displays college contact information.
* 🧭 **Navigation Menu:** Enables users to navigate between website sections.
* ⚡ **Interactive Elements:** Uses JavaScript to support event-related actions.
* 🌐 **Live Deployment:** Makes the website accessible online through Render.
* 📱 **Viewport Support:** Includes responsive viewport configuration for different screen sizes.

## ⚙️ Installation and Setup

Follow these steps to run the College Event Portal locally.

### Prerequisites

Install the following tools:

* A modern web browser, such as Google Chrome or Microsoft Edge
* Visual Studio Code (recommended)
* Git (optional, for cloning the repository)

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/dineshrajasujithra04/CollegeEventPortal.git
```

### 2. Navigate to the Project Folder

```bash
cd CollegeEventPortal
```

### 3. Open the Project

Open the folder in Visual Studio Code:

```bash
code .
```

Alternatively, open the folder directly from VS Code using **File → Open Folder**.

### 4. Run the Website

**Option A — Open directly**

Open the project folder and double-click `index.html`.

**Option B — Use Live Server**

1. Open the project in VS Code.
2. Install the Live Server extension if necessary.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website will open in your browser.

> This project is a static front-end application and does not require `npm install`, a Node.js backend, or a database to display the website.

## 🧭 How to Use

1. Open the College Event Portal website.
2. Explore the TechFest 2026 homepage.
3. Use the navigation menu to access different sections.
4. Browse the event cards to learn about competitions.
5. Use the registration form to enter participant details and select an event.
6. Review the event schedule for dates, timings, and venues.
7. Explore the event gallery.
8. Visit the contact section for the displayed contact information.

**Note:** The registration form's ability to store or submit registrations depends on the JavaScript implementation and any connected backend. A front-end form alone does not provide permanent database storage.

## 🧠 How It Works

The project uses three core front-end technologies:

* **HTML5** defines the content and structure of the portal.
* **CSS3** controls the visual appearance, layout, and presentation.
* **JavaScript** provides interactive behavior, such as responding to button clicks and handling event-related actions.

The HTML page connects the stylesheet using `style.css` and loads the JavaScript using `script.js`.

### Deployment Configuration

For a repository containing `index.html`, `style.css`, and `script.js` in its root directory, use these Render settings:

| Setting           | Value       |
| ----------------- | ----------- |
| Service Type      | Static Site |
| Branch            | `main`      |
| Root Directory    | Leave blank |
| Build Command     | Leave blank |
| Publish Directory | `.`         |

If automatic deployment is enabled, pushing changes to the connected GitHub repository can trigger a new deployment.
